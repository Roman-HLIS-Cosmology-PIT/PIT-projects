# PIT projects

[Submit an EP project](https://github.com/Roman-HLIS-Cosmology-PIT/PIT-projects/issues/new?template=new-project.yml)

Propose an Enhancing Project for Steering Committee review. Collaboration members can submit without a fork or repository write access.

[Declare a CPP — SC only](https://github.com/Roman-HLIS-Cosmology-PIT/PIT-projects/issues/new?template=new-cpp-project.yml)

Declare an unassigned Critical Path Project. Submission and edits require active Steering Committee membership.

[Claim an available CPP](https://github.com/Roman-HLIS-Cosmology-PIT/PIT-projects/issues/new?template=claim-cpp.yml)

Request assignment of an accepted, unassigned CPP. Assignment takes effect after SC accepts the review PR.

Stay on the Issue page for the automated result. A validated submission opens a review PR; merging accepts it. Include only information suitable for everyone with repository access.
